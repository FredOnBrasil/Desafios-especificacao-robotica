# Desafios de Especificação de Robôs Industriais

Aplicação educacional interativa desenvolvida para auxiliar os alunos no aprendizado dos conceitos relacionados à especificação e seleção de robôs industriais.

## Sobre o projeto

O aplicativo apresenta desafios práticos organizados em três trilhas

- Trilha A – Seleção de Robôs análise de requisitos e escolha de robôs adequados para diferentes aplicações industriais.
- Trilha B – Cálculo Aplicado resolução de problemas envolvendo parâmetros técnicos e dimensionamento.
- Trilha C – Diagnóstico Crítico análise de situações-problema e tomada de decisões técnicas.

## Como utilizar

1. Acesse o aplicativo pelo navegador.
2. Informe seu nome, quando solicitado.
3. Explore as orientações e os exemplos disponíveis.
4. Resolva os desafios das três trilhas.
5. Confira sua pontuação e o progresso alcançado.
6. Registre capturas de tela dos resultados para comprovar sua participação.

## Observações

- O aplicativo funciona diretamente no navegador, sem necessidade de instalação.
- O progresso é armazenado localmente no navegador por meio do `localStorage`.
- Os dados não são enviados automaticamente para um servidor.
- Para fins de avaliação, os alunos devem registrar e entregar as evidências solicitadas pelo instrutor.

## Objetivo educacional

Estimular o raciocínio lógico, a interpretação de dados técnicos, a capacidade analítica e a tomada de decisões fundamentadas em situações relacionadas à robótica industrial.
